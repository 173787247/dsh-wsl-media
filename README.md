# dsh-wsl-media

> **语言：** **中文**（本页） · [English](./README.en.md)

WSL 本地媒体 / 文档管线（**0.2.0**）：ffprobe、ffmpeg 抽音轨/缩略图、pdftotext、whisper ASR、pandoc、tesseract OCR、exiftool。

路径必须在白名单根下。

## 工具

`media_status` · `media_probe` · `media_extract_audio` · `media_thumbnail` · `media_pdf_text` · `media_asr` · `media_pandoc` · `media_ocr` · `media_exif`
